Обзор отделов Мини-станции. Иконки на главной — ID-карты из сборки.

## Отделы

| Отдел | Чем заняты | С чего начать |
|-------|------------|---------------|
| Командование | смена, криз, приоритеты | капитан / головы |
| Безопасность | закон, бриг, патруль | [[Security Officer|Офицер СБ]], [[Космический Закон]] |
| Инженерия | энергия, атмос, ремонт | [[Руководство по инженерии]] |
| Медицина | лечение, химия, хирургия | [[Руководство по химии]], [[Руководство по хирургии]] |
| Наука | исследования, роботы | аномалии / латы |
| Снабжение | карго, утиль, шаттл | заказы и руда |
| Сервис | кухня, бар, уборка, сервис | [[Руководство по еде]] |
| Синтетики | ИИ, борги | законы и модули |
| ЦентКом | ERT / ЦК | поздний ответ на криз |
| НИКК Тайпан | контент Тайпана в билде | отдельные роли `_Mini` |
