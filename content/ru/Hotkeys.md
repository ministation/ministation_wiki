Основные клавиши Space Station 14 (сборка Мини-станции). Точный список всегда можно открыть в настройках клиента.

## Часто нужное

| Клавиша | Действие |
|---------|----------|
| `T` / `Y` | чат / радио (зависит от раскладки настроек) |
| `Tab` | инвентарь / хотбар |
| `Z` / `X` / `C` / `V` | действия на хотбаре (часто) |
| `F` | переключить бой / бросок (см. настройки) |
| `Ctrl` + клик | альтернативное взаимодействие |
| `Alt` + клик | осмотр / вторичное действие |
| `Shift` + клик | осмотр сущности |
| `Q` | выбросить предмет |
| `E` | использовать / активировать |
| `1–0` | слоты хотбара |

Если хоткей «не тот» — откройте **Настройки → Управление** и проверьте конфликты с раскладкой ОС.
